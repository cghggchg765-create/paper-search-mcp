# Claude Code Skill 安装

将本目录下的 `skill.md` 复制到 Claude Code skills 目录：

```bash
# Windows
mkdir -p ~/.claude/skills/paper-search
cp skill.md ~/.claude/skills/paper-search/

# Linux/macOS
mkdir -p ~/.claude/skills/paper-search
cp skill.md ~/.claude/skills/paper-search/
```

重启 Claude Code 后即可使用 `/paper-search` 命令。
